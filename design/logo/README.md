# SedotDeck logo

A handheld taking a sip through a straw: SedotDeck *sedot*s (slurps) updates into your Deck.

Everything in [`kit/`](kit) is generated by [`build_kit.py`](build_kit.py) from plain geometry on a 256 grid. Change the
script, not the files, then run `python build_kit.py`. PNGs and the `.ico` are rendered from the SVGs with the
`logo-design` skill's `render_png.py`.

## Files

| File | Use |
|---|---|
| `app-icon.svg`, `png/app-icon-{128,256,512}.png` | App icon: dark tile, light body, blue straw. Also `assets/icon.svg` and the Tauri icons. |
| `app-icon-small.svg`, `png/app-icon-{32,64}.png`, `favicon.ico` | Small-size cut for 16–64 px (no stick holes, thicker straw). Also the web UI's favicon. |
| `symbol-on-dark.svg` / `symbol-on-light.svg` | The mark without a tile, in colour. |
| `symbol-small-on-dark.svg` | Small cut without a tile; the web UI header uses it at 30 px. |
| `symbol-black.svg`, `symbol-white.svg`, `symbol-small-black.svg` | One colour, for print, stamps, Decky's plugin icon. |
| `lockup-horizontal-*.svg`, `png/lockup-horizontal-*-1200.png` | Mark + name side by side: README headers, banners. |
| `lockup-stacked-*.svg` | Mark above the name: square spaces, splash screens. |

## Colour

| Name | HEX | Where |
|---|---|---|
| Straw blue | `#1a9fff` | Straw on dark backgrounds and on the app icon |
| Deep blue | `#1475c4` | Straw on light backgrounds (keeps contrast on white) |
| Light | `#e6e8eb` | Body and name on dark backgrounds |
| Ink | `#0f1115` | Body and name on light backgrounds |
| Tile | `#1a1d23` | App icon background |

The same values are the UI's colour tokens. In one colour, the whole mark is a single colour; never colour only the body.

## Rules

- **Clear space:** keep free space around the mark at least the straw's width (22 units on the 256 grid) on every side.
- **Minimum size:** the regular mark from 48 px; below that use the small cut. The horizontal lockup from 120 px wide.
- **Backgrounds:** "on dark" files on dark greys or black, "on light" files on white or light greys. Photos only with
  enough contrast behind the whole mark.
- **Don't:** stretch or rotate it, change the straw's angle, add shadows, glows or gradients, put the colour mark on a
  busy picture, or retype the name in a font. The wordmark is drawn, not typed.

## Wordmark

The name is drawn as monoline strokes with round ends, the same stroke language as the straw, so it needs no font and
no font licence. It is kept as strokes on purpose (it scales cleanly as SVG); convert strokes to outlines in a vector
editor if a printer or cutter needs filled shapes.

## Notes

- The handheld is deliberately generic (no trackpads, no brand details), not a drawing of Valve's Steam Deck.
- No trademark search has been done. Check before registering the name or the mark.
- `desktop/src-tauri/icons/icon.icns` (macOS only, not built) still has the old icon.
